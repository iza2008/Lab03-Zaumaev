## ПР3. Ответы на контрольные вопросы

1. `x += 5` — краткая запись `x = x + 5`. Для простой переменной итоговое значение одинаковое: к `x` прибавляется 5.
2. `x++` сначала возвращает прежнее значение, а затем увеличивает `x`. `++x` сначала увеличивает `x`, а затем возвращает новое значение. Если результат используется сразу, это влияет на выражение.
3. Оператор сравнения возвращает значение типа `bool`: `true` или `false`.
4. Короткое замыкание означает, что C# не вычисляет правую часть, когда результат уже известен. В `a && b` при `a == false` часть `b` не нужна; в `a || b` при `a == true` часть `b` не нужна. Например, `name != null && name.Length > 0` сначала проверяет, что `name` не равен `null`, и только после этого обращается к `Length`.
5. В выражении `10 - 2 * 3 + 4 / 2` сначала выполняются умножение и деление: `10 - 6 + 2`. Сложение и вычитание выполняются слева направо: `10 - 6 = 4`, `4 + 2 = 6`. Ответ: `6`.
6. Скобки показывают порядок вычислений явно и помогают человеку быстрее понять выражение, а также уменьшают риск ошибки при изменении кода.
